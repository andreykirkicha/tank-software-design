# tank-software-design

## Заполнение уровня

По умолчанию игра загружает карту `src/main/resources/level.txt`. Карта должна быть
прямоугольной и содержать ровно один танк:

- `T` — дерево;
- `X` — начальная позиция танка;
- `_` — пустая клетка.

Первая строка файла соответствует верхнему ряду игрового поля.

Для запуска со случайной позицией танка и случайными деревьями:

```shell
./gradlew run --args="--random"
```

Без аргумента используется карта из файла:

```shell
./gradlew run
```

В обоих режимах в случайных свободных клетках появляются ещё четыре танка.
Танк из карты (или первый танк случайного уровня) управляется стрелками и WASD.
Остальные перед каждым шагом выбирают одно из четырёх случайных направлений.
Если путь закрыт деревом, танком или границей уровня, шаг не выполняется.
Пока танк едет, его исходная и целевая клетки заняты; исходная освобождается
после завершения анимации.

Управление реализовано через `ControlStrategy`: клавиатурная и случайная стратегии
создают `MoveCommand`, а `TankController` выполняет команду, когда танк свободен.
Проверки столкновений и резервирование клеток находятся в `GameField`.

Запуск тестов логики без графики:

```shell
./gradlew test
```
