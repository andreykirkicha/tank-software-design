# tank-software-design

## Заполнение уровня

По умолчанию игра загружает карту `src/main/resources/level.txt`. Карта должна быть
прямоугольной и содержать ровно один танк:

- `T` — дерево;
- `X` — начальная позиция танка;
- `_` — пустая клетка.

Первая строка файла соответствует верхнему ряду игрового поля.

Для запуска со случайной позицией танка и случайными деревьями:

```shell
./gradlew run --args="--random"
```

Без аргумента используется карта из файла:

```shell
./gradlew run
```

В обоих режимах в случайных свободных клетках появляются ещё четыре танка.
Танк из карты (или первый танк случайного уровня) управляется стрелками и WASD.
Пробел — выстрел в направлении танка; при удержании огонь повторяется раз в 0,4 с.
Выстрел имеет приоритет над движением. Во время движения танк завершает текущий
шаг, прежде чем принять следующую команду. Остальные танки случайно выбирают
одно из пяти действий: четыре направления движения или выстрел.
Если путь закрыт деревом, танком или границей уровня, шаг не выполняется.
Пока танк едет, его исходная и целевая клетки заняты; исходная освобождается
после завершения анимации.

Управление реализовано через `ControlStrategy`: клавиатурная и случайная стратегии
создают `MoveCommand` и `ShootCommand`, а `TankController` запрашивает команду,
когда танк свободен и перезарядка завершена. Рекомендательный движок не используется.

Пуля появляется в следующей клетке перед танком и проходит одну клетку за 0,1 с.
При столкновении с деревом, танком или другой пулей она удаляется; при столкновении
двух пуль исчезают обе. За границей поля пуля также удаляется. Столкновение
проверяется сразу при создании пули, поэтому выстрел в соседний танк наносит урон
немедленно. Деревья остаются на месте. При движении танк может получить попадание
в исходную и целевую клетки, пока они заняты.

По умолчанию у танка 100 здоровья, у пули — 50 урона. Их можно настроить через
конструктор `Tank(x, y, direction, health, bulletDamage)`. Согласно условию танк
удаляется при здоровье **меньше нуля**; при нуле он ещё жив. Уничтоженный танк
освобождает обе занятые клетки и больше не выполняет команды.

Клавиша **L** включает и выключает полоски здоровья всех танков уровня. Изначально
полоски скрыты; удержание клавиши переключает их только один раз. Полоски следуют
за танками во время движения и показывают долю оставшегося здоровья относительно
начального (`getMaxHealth()`), уменьшаясь и меняя цвет при попаданиях.
При нулевом здоровье остаётся пустая полоска. Переключение работает также во время
движения, перезарядки и после уничтожения танка игрока.

`ToggleHealthBarsCommand` реализует шаблон «Команда» и переключает общее состояние
в `GameFieldGraphics`. `HealthBarGraphicsDecorator` реализует шаблон «Декоратор»:
оборачивает обычную графику танка и при включённом отображении дополнительно
рисует `HealthBarGraphics`. Новые танки используют то же состояние видимости;
при удалении танка освобождаются ресурсы и его изображения, и полоски.

Каждый кадр состоит из четырёх этапов: создание всех команд, их выполнение,
`GameField.live(tick)` для обновления объектов, затем отрисовка. Время движения,
перезарядка и столкновения рассчитываются в логике и не зависят от графики.

`GameField` публикует добавление и удаление объектов через `GameFieldListener`
(шаблон «Наблюдатель»). При подписке слушатель получает все начальные объекты теми
же событиями. `GameFieldGraphics` подписывается на уровень, создаёт представления
танков, деревьев и пуль, а при удалении освобождает их графические ресурсы.

Запуск тестов логики без графики:

```shell
./gradlew test
```
